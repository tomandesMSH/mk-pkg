Identifies and intercepts input from a second (macro) keyboard via the [Interception](https://github.com/oblitum/Interception) driver,

This way, you can use one of your keyboards as a dedicated controller for your app - triggering actions
instead of typing - while your other keyboard keeps working normally in Windows.

Currently used by [SoundpadTranslator](https://github.com/tomandesMSH/SoundpadTranslator) and
[Keyboard Utils](https://github.com/tomandesMSH/Keyboard-Utils), and will be used for more of my projects.
